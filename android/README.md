# StudyMate Android

Мобільний застосунок StudyMate для Android, написаний мовою Kotlin.

## Локальна історія завдань

HistoryDatabase.kt відповідає за роботу з SQLite.
MainActivity.kt забезпечує збереження, перегляд
та видалення результатів аналізу.
activity_main.xml містить кнопку історії завдань.

Дані зберігаються локально на пристрої.
Неуспішні запити не додаються до історії.
