Визначати високий, середній або низький пріоритет за текстом завдання. Відображати результат в Android.

## Лабораторна робота 3

- Автоматичне визначення пріоритету завдання.
- Підтримка трьох рівнів пріоритету.
- Кольорове відображення пріоритету в Android.
- Збереження сумісності API.
- Обробка порожнього введення та помилок мережі.

## Вимоги Lab 4

- Автоматично зберігати успішні результати аналізу.
- Зберігати текст завдання, категорію, рекомендацію,
  пріоритет, дату та статус.
- Відображати список збережених завдань.
- Відкривати детальну інформацію про запис.
- Видаляти записи після підтвердження.
- Зберігати історію після перезапуску.
- Забезпечувати доступ до історії без сервера.
- Не зберігати результати неуспішних запитів.
