# AI prompts

Нижче наведено узагальнені формулювання запитів
та результати роботи над Lab 3.

## 1. Аналіз
Запит: Проаналізуй архітектуру StudyMate та потік даних.
Результат: визначено Android, FastAPI та компонент аналізу.

## 2. Планування
Запит: Запропонуй мінімальні зміни для визначення пріоритету.
Результат: обрано реалізацію без зміни API-контракту.

## 3. Реалізація
Запит: Додай три рівні пріоритету за ключовими словами.
Результат: реалізовано автоматичне визначення пріоритету.

## 4. Debugging
Запит: Виправ визначення пріоритету для фрази
"Завдання не термінове".
Результат: додано обробку заперечення терміновості.

## 5. Тестування
Запит: Перевір високий, середній і низький пріоритети,
порожнє введення та недоступність backend.
Результат: контрольні сценарії пройдено.

## 6. Підсумок
Запит: Онови документацію відповідно до реалізації.
Результат: доповнено Knowledge Base та описано обмеження.
