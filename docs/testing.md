Перевірити три рівні пріоритету, порожній запит, недоступність сервера та повторний запит.

## Контрольні сценарії Lab 3

| Сценарій | Очікуваний результат | Статус |
|---|---|---|
| Терміново здати лабораторну | Високий, червоний | PASS |
| Підготувати презентацію | Середній, помаранчевий | PASS |
| Прочитати книгу у вільний час | Низький, зелений | PASS |
| Завдання не термінове | Низький | PASS |
| Порожній запит до API | HTTP 400 | PASS |
| GET /health | HTTP 200 | PASS |
| Backend недоступний | Повідомлення про помилку | PASS |
| Повторний запит після запуску | Успішний результат | PASS |
