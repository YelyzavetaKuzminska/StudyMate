# Правила роботи coding agent

1. Прочитати Knowledge Base та структуру репозиторію.
2. Пояснити поточну реалізацію.
3. Запропонувати план та перелік файлів.
4. Виконувати мінімальні локальні зміни.
5. Не змінювати API без обґрунтування.
6. Не додавати зайві залежності.
7. Не зберігати секрети в коді або Git.
8. Додавати або оновлювати тести.
9. Підсумувати зміни, перевірки та ризики.
