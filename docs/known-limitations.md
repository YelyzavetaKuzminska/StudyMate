# Відомі обмеження

- Аналіз базується на ключових словах.
- Можлива неправильна інтерпретація складних фраз.
- Для роботи додатка потрібен запущений backend.
- Немає історії завдань та авторизації.
- Android використовує локальну адресу backend.

## Обмеження Lab 4

- Історія зберігається локально в SQLite.
- Синхронізація між пристроями відсутня.
- Для нового аналізу потрібен доступ до backend.
- Помилкові та порожні запити не зберігаються.
- Черга офлайн-запитів не реалізована.
- Реалізовано базовий обов'язковий рівень.
