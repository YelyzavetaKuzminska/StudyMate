# AI-компонент StudyMate

Компонент використовує правила та ключові слова для аналізу навчальних завдань.
Вхідні дані: текст завдання.
Результат: категорія, рекомендація та пріоритет.

Пріоритети: високий, середній, низький.
За відсутності ключових слів пріоритет середній.
Заперечення терміновості враховується.
Зовнішні AI API не використовуються.
