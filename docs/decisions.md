# Технічні рішення

- Kotlin та XML для Android.
- FastAPI для backend.
- REST API та JSON для обміну даними.
- Аналіз на основі правил без зовнішніх AI API.
- Пріоритет додається до рекомендації без зміни структури API.
- Високий пріоритет позначається червоним, середній помаранчевим, низький зеленим.
