# StudyMate

StudyMate — мобільний застосунок для студентів.

## Проблема
Студентам складно організовувати навчальні завдання
та визначати їхню важливість.

## Цільова аудиторія
Студенти закладів вищої освіти.

## Основний сценарій
1. Користувач вводить навчальне завдання.
2. Android надсилає запит до backend.
3. Backend визначає категорію, рекомендацію та пріоритет.
4. Android відображає результат із кольоровим пріоритетом.

## Межі MVP
Аналіз текстових завдань без авторизації,
бази даних та зовнішніх AI-сервісів.
