StudyMate

StudyMate — це концепція мобільного Android-застосунку для студентів, який допомагає організовувати навчальний процес, планувати завдання та відстежувати прогрес.

Сфера застосування

Освіта.

Мета застосунку

Допомогти студентам ефективно керувати навчальними завданнями, контролювати дедлайни та бачити результати своєї роботи.

Основні функції

Додавання нових навчальних завдань.

Встановлення дедлайнів для завдань.

Перегляд списку запланованих завдань.

Позначення завдань як виконаних.

Відстеження навчального прогресу.

Технології

Мова програмування: Kotlin

Середовище розробки: Android Studio

Інтерфейс: XML

Зберігання даних: локальна база даних (заплановано)

Поточний стан проєкту

У межах лабораторної роботи №1 налаштовано середовище Android Studio, створено та запущено базовий застосунок Hello World на емуляторі Android. Також розроблено концепцію, архітектурну діаграму та функціональні вимоги до майбутнього застосунку StudyMate.

Подальший розвиток

Планується реалізація інтерфейсу, додавання та редагування завдань, збереження даних і відображення прогресу студента.
